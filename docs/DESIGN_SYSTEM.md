# Дизайн-система «Фокус»

Источник истины для сайта и Figma. Все значения продублированы CSS-переменными
в `frontend/src/styles/tokens.css`.

## 1. Идея

Спокойное рабочее пространство: тёплая бумажная поверхность, один глубокий
зелёный акцент, крупная типографика и один понятный сценарий — выбрать дело,
запустить фокус, увидеть результат. Референс сохранён по структуре: задачи
слева, таймер справа, статистика сверху, модальные окна и состояния таймера.

## 3. Типографика

Семейство: `Inter, "SF Pro Text", -apple-system, ...`; таймер — системный
моноширинный (`SF Mono`, `JetBrains Mono`).

| Роль | Размер / вес | Пример |
| --- | --- | --- |
| Display | 36–52 / 560 | «Место для работы, которая важна.» |
| H1 | 28–36 / 650 | «Добрый день, Анна.» |
| H2 | 22 / 650 | «Мои задачи» |
| H3 | 18 / 650 | заголовки секций |
| Body | 15 / 400 | текст |
| Small | 13 / 400 | meta, подсказки |
| Micro | 10–11 / 650, uppercase, +0.1em | eyebrow, лейблы |
| Timer | 54–80 / 500, mono, tabular | `24:32` |

## 4. Сетка и отступы

- Контейнер: `max-width 1180px`, боковые поля `clamp(18px, 4vw, 40px)`.
- Шаг: 4 px. Основные значения: 4, 8, 12, 16, 20, 24, 32, 40, 56, 72.
- Заголовок страницы: eyebrow + H1 + подзаголовок, затем stat-strip, затем grid.
- Dashboard: `1.45fr / 1fr`, gap 24 px; правая колонка sticky на desktop.
- Auth: split 50/50, карточка 430 px.
- Settings: колонка 780 px.
- Радиусы: 6, 9, 12, 18, 24, pill.
- Тени: только `shadow-xs` для карточек и `shadow-md` для модальных окон/меню.

## 5. Компоненты

### Кнопки
- Primary: фон `accent`, белый текст, 42 px, радиус 9 px.
- Secondary: белая поверхность, граница `line-strong`.
- Ghost, danger, danger-ghost, icon, link.
- Размеры sm (34), md (42), lg (48). Loading = spinner + disabled.
- Focus-visible: кольцо `0 0 0 3px rgba(30,91,65,.24)`.

### Поля
- Высота 44 px, радиус 9 px, граница `line-strong`; focus — accent + ring.
- Label 13 px / 620; hint 12 px; error 12 px с иконкой.
- Password: иконка замка слева, eye справа.
- Date: нативный picker, без второго декоративного значка.

### Карточки и панели
- Surface, 1 px border, radius 18–24, shadow-xs.
- Panel head 20 px, toolbar 14×20, список строк 13×20.

### Segmented / chips / badges
- Segmented: подложка `surface-2`, активный сегмент — белая карточка.
- Chips — pill с иконкой; badges — компактный статус.

### Task row
- Круговой чекбокс 20 px; заголовок 14.5 px; meta 11.5 px.
- Selected: левая акцентная полоса 2 px, фон `accent-soft` 52%.
- Actions: target / pencil / trash, появляются при hover/focus, всегда на touch.
- Completed: line-through, приглушённый цвет.

### Focus panel
- Заголовок-eyebrow «Работа над задачей», справа «Сегодня · N».
- Название задачи, режим, крупный таймер, progress bar, 4 точки цикла.
- Idle: 3 режима 25/5/15.
- Running: primary «Пауза» + icon «Завершить».
- Paused: «Продолжить» + «Завершить».
- Break: фон `accent-soft`, границы `accent-line`, подпись «Перерыв запущен автоматически».
- Предложение перерыва: success-alert с кнопкой «Начать» и закрытием.

### Модальные окна
- Overlay `rgba(23,27,24,.42)` + blur 3 px.
- Панель 480 px, radius 24, заголовок 22, footer с отменой/действием.
- На мобильном — bottom sheet.
- Esc, клик по фону, focus trap, возврат фокуса.

### Уведомления
- Bottom-right, 360 px, левая цветная полоса, title/body, close, auto-dismiss.
- Дубликаты с одинаковым текстом заменяются, максимум 3 одновременно.
- На мобильном подняты над bottom-nav.

### Состояния
- Loading: skeleton для списков и графика, spinner в кнопках.
- Empty: иконка в мягком квадрате, заголовок, объяснение, действие.
- Error: alert с иконкой и retry.
- Success: inline alert / toast.
- Disabled: opacity .56, без hover-подъёма.

## 6. Экраны

1. **Вход** — split-layout; форма email/пароль, show password, ошибка inline, ссылки.
2. **Регистрация** — имя, email, пароль, подтверждение, валидация, авто-вход.
3. **Восстановление** — email, success-экран, повторная отправка, dev-ссылка.
4. **Новый пароль** — токен из URL, валидация, success.
5. **Обзор** — приветствие, 3 stats, задачи (фильтры/поиск/сортировка), focus panel.
6. **Новая/редактирование задачи** — модальное окно, название + дедлайн.
7. **Статистика** — 4 метрики, недельный график, по задачам, история.
8. **Настройки** — профиль, пароль, уведомления, аккаунт, danger zone.
9. **404** — спокойный экран с действиями.
10. **Состояния таймера** — idle, running, paused, break, completed.

## 7. Адаптивность

- ≥1081: 2 колонки, sticky-таймер.
- 961–1080: 2 колонки, компактные stats.
- ≤960: одна колонка, таймер первым, auth-aside становится полосой.
- ≤820: скрывается desktop-nav, появляется bottom-nav, stats в 3 колонки.
- ≤680: toolbar в две строки, модальные окна как bottom sheet, таблицы скроллятся внутри контейнера.
- ≤420: кнопки таймера в столбец, уменьшенные поля.
- Горизонтальный скролл страницы запрещён; проверяется на 390/768/1024/1440.

## 8. Доступность

- Контраст текста ≥ 4.5:1 (основной/вторичный).
- Все поля с label; ошибки `role="alert"`; статус таймера `role="status"`.
- Focus-visible кольцо на всех интерактивных элементах.
- Кнопки-иконки имеют aria-label; чекбокс — aria-pressed.
- Модальные окна: `role="dialog"`, `aria-modal`, focus trap, Esc.
- `prefers-reduced-motion` отключает анимации.
- Skip-link к основному содержимому.
